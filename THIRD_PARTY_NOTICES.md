## Research Reference

Li et al. (2025), *Coalescence of multiple pairs of levitated droplets using dual-side phased arrays.*

https://doi.org/10.1016/j.ultsonch.2025.107327

The phase optimization module in this repository is inspired by the published DS-PAT approach and adapted for a single active array with a passive acoustic reflector.

## Project Modifications

This project extends the original open-source systems with a reflector model, modified control software, and integration for experimental liquid-droplet levitation and coalescence.
