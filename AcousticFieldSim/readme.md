### How to Run

The application can be launched in two ways:

**Option 1: Direct Launch (Windows)**
- Run `START_DPCAT.bat` to launch the GUI.
- Requires Java and the compiled JAR (`dist/AcousticField3D.jar`) with its dependencies in `jars/`.

**Option 2: NetBeans IDE**
- Open NetBeans and select `File → Open Project`.
- Select the `AcousticFieldSim` folder.
- Ensure the required Java libraries are configured.
- Click `Clean and Build`, then press `F6` to run.

Both methods launch the same Java application. NetBeans is recommended for development, while the BAT launcher is intended for direct use.
